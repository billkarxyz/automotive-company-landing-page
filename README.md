# Automotive Company Landing Page

Landing page statis untuk **All New Toyota Yaris Cross HEV** — dibuat sebagai contoh/demo halaman perusahaan otomotif.

## Cara membuka

- Buka `index.html` langsung di browser, atau
- Aktifkan GitHub Pages (Settings → Pages → Branch `main`, folder `/ (root)`).

Tidak butuh build step, dependensi, atau backend.

## Fitur

- Navigasi atas: Specifications, Yaris, Technology
- Hero dengan foto mobil, headline "ALL NEW YARIS CROSS HEV", dan tombol ORDER (merah) yang menggulir ke formulir pemesanan
- Strip statistik: 116 PS, 31 km/L, 210 mm ground clearance
- Specifications dengan 3 tab: Mesin & Performa, Dimensi & Kapasitas, Fitur & Keselamatan
- Technology: Hybrid EV System, Toyota Safety Sense, Panoramic View Monitor
- 7 varian dengan harga OTR Jakarta — klik kartu varian untuk memilihnya di simulasi kredit dan formulir pemesanan
- Simulasi kredit interaktif: atur DP (%), tenor, dan bunga flat (%/tahun) — angsuran bulanan dihitung langsung di browser
- Formulir pemesanan (nama, telepon, varian, kota) yang menghasilkan ringkasan pesanan dan bisa disalin
- Galeri foto dengan lightbox (klik foto untuk memperbesar, Esc untuk menutup)
- Foto memakai URL publik Unsplash; bila sebuah gambar gagal dimuat, tampilannya tetap rapi (latar gelap sebagai fallback)

## Disclaimer harga

Harga yang tercantum adalah harga OTR Jakarta. Varian 1.5 G HV CVT (Rp399.000.000), 1.5 S HV CVT (Rp430.000.000), dan 1.5 S HV CVT TSS (Rp448.800.000) merujuk pada daftar harga publik terkini; varian lain yang bertanda "Harga Contoh" adalah harga contoh (sample) untuk keperluan demo. Harga dapat berubah sewaktu-waktu — konfirmasi ke dealer resmi Toyota. Halaman ini bukan situs resmi Toyota maupun dealer, dan tidak ada data pemesanan yang dikirim ke mana pun.
